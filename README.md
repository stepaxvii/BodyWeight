# PixelFit (BodyWeight)

Telegram Mini App — фитнес-трекер с геймификацией в стиле 8-bit.

---

## Начисление XP

### Почему награда за одну и ту же тренировку может отличаться?

Награда (XP и монеты) считается не только по программе, но и по контексту: стрик, первая ли тренировка за день, объём, длительность и разовые бонусы.

| Фактор | Влияние |
|:-------|:--------|
| **Стрик** (дни подряд) | XP: множитель до 1.5×. Монеты: +1 за каждые 7 дней стрика (макс. 4). |
| **Первая тренировка за день** | XP: +20% только у первой тренировки за день. |
| **Объём** (подходы/повторения) | XP: считается по каждому подходу; разный ввод → разный XP. |
| **Длительность ≥ 45 мин** | Монеты: +1 за тренировку от 45 минут. |
| **Повышение уровня** в этой тренировке | Монеты: +5 за каждый новый уровень. |
| **Достижения / цели** в этой тренировке | Монеты: бонусы за разблокировку достижения или выполнение цели. |

Логика начисления: `backend/app/services/workout_processor.py`, `backend/app/services/xp_calculator.py`.

## Сервер

**Очистка после пересборок** (образы, кэш Docker, артефакты фронта):

```bash
bash scripts/cleanup-server.sh
```

Том `./data` (БД) не трогается. После очистки скрипт удаляет `frontend/mini-app/node_modules` — перед сборкой фронта снова установите зависимости (из **корня репозитория**):

```bash
cd frontend/mini-app && npm ci && npm run build && cp -r build/* ../../backend/static/
```

Если вы уже в `frontend/mini-app`:

```bash
npm ci && npm run build && cp -r build/* /home/BodyWeight/backend/static/
```
