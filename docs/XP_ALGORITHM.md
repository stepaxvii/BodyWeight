# Алгоритм начисления XP

**Версия**: 3.0
**Дата**: 30.05.2026
**Статус**: Финальная спецификация

---

## 🎯 Основные принципы

1. **XP пропорционален суммарному объёму упражнения** (повторам или времени).
2. **Количество подходов НЕ влияет на XP.** 30 отжиманий дают одинаковый XP, как ни разбей: 1×30, 3×10, 6×5 — везде поровну.
3. **Сложность зашита в `base_xp`** — отдельного множителя сложности нет.
4. **Backend — единственный источник истины** для финального расчёта.
5. **Frontend показывает превью**, которое в точности повторяет формулу бэкенда (включая стрик).
6. **Ценность тренировки растёт от разнообразия** — общий XP = сумма по упражнениям.

---

## 📐 Формула XP

### Ценность одного повтора

```
xp_per_rep = base_xp × XP_PER_REP_RATE + XP_PER_REP_BONUS
```

### Упражнения на повторы

```
XP = floor(total_reps × xp_per_rep × streak_mult)
```

### Упражнения на время (timed)

```
rep_equiv = total_seconds / 10        # 10 секунд = 1 «повтор-эквивалент»
XP = floor(rep_equiv × xp_per_rep × streak_mult)
```

Где:
- `total_reps` / `total_seconds` — **сумма по всем подходам** упражнения.
- `XP_PER_REP_RATE = 0.3` — даёт классическому отжиманию (`base_xp = 10`) 3 XP/повтор от ставки.
- `XP_PER_REP_BONUS = 1` — плоский +1 к каждому повтору (компенсирует убранные множители сложности и первой тренировки). Итого отжимание = **4 XP за повтор**.
- `streak_mult` — см. ниже.

### Компоненты

#### base_xp
Базовая ценность упражнения из БД. Уже отражает сложность.
Примеры: отжимания от стены = 5, классические отжимания = 10, бёрпи = 15.
Ценность одного повтора = `base_xp × 0.3 + 1` (от стены = 2.5, классические = 4, бёрпи = 5.5, приседание ≈ 3).

#### streak_mult (множитель серии)
```
streak_mult = 1 + min(streak_days, 7) / 7 × 0.5
```
Линейно растёт до **+50% за 7 дней**, дальше — потолок.

| Серия | Множитель |
|-------|-----------|
| 0 дней | ×1.00 |
| 1 день | ×1.07 |
| 3 дня | ×1.21 |
| 7+ дней | ×1.50 |

Применяется ко **всем** видам активности: повторы, время, велосипед, ходьба.

---

## ⏱️ Timed-упражнения

- **10 секунд = 1 повтор-эквивалент**, считается от **суммарного** времени.
- Конвертация: `rep_equiv = total_seconds / 10` (без округления внутри, floor — в конце).
- Как и повторы, зависит только от суммарного времени и не зависит от числа подходов.

**Примеры:** 60 секунд → 6 rep-эквивалентов; планка `base_xp=10` → `6 × 10 × 0.3 = 18 XP`.

## 🔄 Алгоритм расчёта тренировки

### Backend (`xp_calculator.py` + `workout_processor.py`)

```python
for exercise_data in workout.exercises:
    exercise = get_exercise(exercise_data.slug)

    # Суммируем объём по всем подходам — границы подходов не важны
    if exercise_data.is_timed:
        total_seconds = sum(exercise_data.sets)
        xp = calculate_timed_xp(exercise.base_xp, total_seconds, user.current_streak)
    else:
        total_reps = sum(exercise_data.sets)
        xp = calculate_exercise_xp(exercise.base_xp, total_reps, user.current_streak)

    total_xp += xp   # floor делается внутри каждого упражнения, затем суммируется
```

### Frontend (`lib/utils/xp.ts`)

Те же функции `calculateExerciseXp` / `calculateTimedXp` (зеркало бэкенда),
используются во всех превью: активная тренировка, офлайн-оценка, маршруты.

```typescript
const totalVolume = data.sets.reduce((sum, v) => sum + v, 0);
total += data.isTimed
    ? calculateTimedXp(data.exercise.base_xp, totalVolume, userStore.streak)
    : calculateExerciseXp(data.exercise.base_xp, totalVolume, userStore.streak);
```

## 📊 Примеры расчёта

### Пример 1: Классические отжимания, 30 повторов (любое разбиение)

**Данные:** base_xp = 10, streak = 0. `xp_per_rep = 10 × 0.3 + 1 = 4`.

```
XP = 30 × 4 × 1.0 = 120 XP
```

1×30, 3×10, 6×5 — **везде 120 XP**.

### Пример 2: Те же отжимания при streak = 7 дней

```
streak_mult = 1.5
XP = 30 × 4 × 1.5 = 180 XP
```

### Пример 3: Планка, 60 секунд (1×60 или 3×20)

**Данные:** base_xp = 10, streak = 0. `xp_per_rep = 4`.

```
rep_equiv = 60 / 10 = 6
XP = 6 × 4 × 1.0 = 24 XP
```

### Пример 4: 100 отжиманий

```
XP = 100 × 4 = 400 XP
```

Линейно: вдвое больше повторов — вдвое больше XP.

---

## ✅ Правила

1. **Подходы не влияют на XP** — учитывается только суммарный объём упражнения.
2. **XP линеен по объёму** — `reps × (base_xp × 0.3 + 1)`.
3. **Timed:** 10 сек = 1 повтор-эквивалент, от суммарного времени.
4. **Streak** применяется ко всей тренировке (до +50% за неделю), ко всем активностям.
5. **Frontend-превью совпадает с бэкендом** — те же функции, включая стрик.

---

## 🎯 Итоговая логика

**Одно упражнение:**
```
XP = floor(total_reps × (base_xp × 0.3 + 1) × streak_mult)           # повторы
XP = floor((total_seconds / 10) × (base_xp × 0.3 + 1) × streak_mult) # время
```

**Вся тренировка:**
```
total_xp = sum(XP_по_каждому_упражнению)
```

**Важно:** объём суммируется по упражнению, число подходов в формуле отсутствует.
