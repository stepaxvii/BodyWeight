## [Unreleased]

### ✨ Новые упражнения

- **Добавлены 4 базовых упражнения для утренней разминки и тренировок**
  - `cobra-stretch` - Растяжка кобра (статическая растяжка для спины и груди)
  - `spinal-twist` - Скручивание позвоночника (улучшает мобильность позвоночника)
  - `glute-stretch` - Растяжка ягодиц (простая и эффективная растяжка)
  - `arm-circle` - Круги руками (разминка плеч)
  - Эти упражнения используются в комплексах "Йога-поток" и тренировках с гантелями

- **Добавлены 10 упражнений с эспандером (resistance band)**
  - Для спины: тяга в наклоне, тяга сидя, вертикальная тяга
  - Для груди: жим от груди, разведение рук
  - Для плеч: жим над головой, разведение в стороны
  - Для ног: приседания, отведение ноги назад
  - Для рук: сгибание на бицепс
  - Все упражнения с тегом `resistance-band` и детальными описаниями техники
  - Диапазон сложности от 1 (начальный) до 2 (средний)
  - XP от 8 до 12 за подход

### 📋 Готовые программы с эспандером

- **6 новых программ тренировок с эспандером**:
  - **Эспандер для начинающих** (25 мин, легко) - базовая тренировка всего тела
  - **Верх тела с эспандером** (30 мин, средне) - грудь, спина, плечи, руки
  - **Низ тела с эспандером** (30 мин, средне) - ноги и ягодицы
  - **Спина-броня** (25 мин, средне) - специализация на спину
  - **Жим-Тяга с эспандером** (35 мин, сложно) - классическая push-pull схема
  - **Тотальная мощь** (40 мин, сложно) - продвинутая силовая тренировка всего тела

### 🔧 Улучшения

- **Добавлена категория "Эспандер" в готовые программы**
  - Новая кнопка "Эспандер" в разделе "Сеты" для быстрого доступа к программам
  - Обновлён тип `RoutineCategory` для поддержки категории "resistance-band"

- **Обновлена фильтрация по оборудованию**
  - Добавлены фильтры "Гантели" и "Эспандер"
  - Теперь можно легко найти упражнения с конкретным оборудованием
  - Фильтры доступны во всех компонентах выбора упражнений

  - Улучшен UX: пользователь сразу видит полную картину отфильтрованных результатов

### 🐛 Исправления

## [1.0.0] - 2024-12-30

### 🎉 Первая рабочая версия

Первая стабильная версия BodyWeight Fitness - Telegram Mini App для отслеживания тренировок с геймификацией.

### ✨ Основные функции

#### 🏋️ Тренировки
- Создание и отслеживание активных тренировок
- Завершение тренировок с автоматическим расчётом XP и монет
- История тренировок с пагинацией
- Статистика за сегодня
- Отмена активных тренировок

#### 💪 Упражнения
- **242 упражнения** с прогрессиями и категориями
- 5 категорий: Strength, Cardio, Static, Dynamic Stretch, Static Stretch
- Фильтрация по категориям, сложности, тегам, оборудованию
- Система избранных упражнений
- Детальная информация об упражнениях
- Прогресс по каждому упражнению (всего повторений, лучший сет, количество выполнений)

#### 🎮 Геймификация
- **Система уровней и XP**
  - Автоматический расчёт XP за каждый подход
  - Формула: `base_xp × difficulty_mult × streak_mult × volume_mult × first_bonus`
  - Убывающая отдача после 20 повторений
  - Бонус за первый подход упражнения
  - Множитель за streak
- **Монеты**
  - Начисление за XP (пороговые значения)
  - Бонус за streak
  - Бонус за длительные тренировки
  - Бонус за достижения
  - Бонус за повышение уровня (5 монет за уровень)
- **Достижения (34)**
  - Автоматическая проверка при завершении тренировки
  - Уведомления о новых достижениях
  - Категории: первая тренировка, серии, объёмы, уровни
- **Streak-система**
  - Отслеживание ежедневных тренировок
  - Множитель XP за streak
  - Визуализация в профиле

#### 🏆 Социальные функции
- **Лидерборды**
  - Глобальный рейтинг по общему XP
  - Недельный рейтинг (XP за неделю)
  - Рейтинг друзей
  - Отображение позиции пользователя
- **Система друзей**
  - Отправка запросов в друзья
  - Принятие/отклонение запросов
  - Список друзей с фильтрацией
  - Просмотр профилей друзей

#### 🎨 Персонализация
- **12 аватаров**
  - Бесплатные: Shadow Wolf, Iron Bear, Fire Fox, Night Panther
  - Платные: Phoenix, Griffin, Cerberus, Thunder Fang, Cyber Ape, Hydra, Minotaur, Kraken, Leviathan, Titan
  - Покупка аватаров за монеты
  - Требования по уровню для премиум аватаров
  - Отслеживание купленных аватаров
- **Профиль пользователя**
  - Статистика: XP, монеты, streak, уровень
  - Общее время тренировок
  - Количество тренировок
  - Достижения
  - Настройки (аватар, уведомления)

#### 📊 Цели
- Создание целей (weekly_workouts, daily_xp, weekly_xp, streak_days)
- Автоматическое обновление прогресса при завершении тренировок
- Отслеживание выполнения целей
- Прогресс в процентах

#### 📱 Программы тренировок
- **Готовые программы**
  - 4 категории: Morning, Home, Pullup Bar, Dip Bars
  - Множество готовых рутин
  - Пошаговое выполнение с таймером
- **Кастомные программы**
  - Создание собственных программ
  - Редактирование программ
  - Удаление программ

#### 🔔 Уведомления

### 🏗️ Технические особенности

- Синхронизированные типы с backend
- Реактивное состояние (stores)
- Пагинация с "Загрузить ещё"
- Адаптивный дизайн
- Telegram WebApp интеграция

#### Telegram Bot
- **Aiogram 3.4**
- Команды для запуска Mini App
- Обработка deep links
