### ✨ Новые упражнения

- **Добавлено упражнение для запястий**
  - `dumbbell-hammer-wrist-curl` - Сгибание запястий (молоток) (силовое упражнение для предплечий и запястий)
  - Нейтральный хват гантелей с изолированным движением запястьями
  - Сложность: средняя (2), XP: 8 за подход, требуется уровень 2

- **Добавлены 4 базовых упражнения для утренней разминки и тренировок**
  - `cobra-stretch` - Растяжка кобра (статическая растяжка для спины и груди)
  - `spinal-twist` - Скручивание позвоночника (улучшает мобильность позвоночника)
  - `glute-stretch` - Растяжка ягодиц (простая и эффективная растяжка)
  - `arm-circle` - Круги руками (разминка плеч)
  - Эти упражнения используются в комплексах "Йога-поток" и тренировках с гантелями

- **Добавлены 10 упражнений с эспандером (resistance band)**
  - Для спины: тяга в наклоне, тяга сидя, вертикальная тяга
  - Для груди: жим от груди, разведение рук
  - Для плеч: жим над головой, разведение в стороны
  - Для ног: приседания, отведение ноги назад
  - Для рук: сгибание на бицепс
  - Все упражнения с тегом `resistance-band` и детальными описаниями техники
  - Диапазон сложности от 1 (начальный) до 2 (средний)
  - XP от 8 до 12 за подход

### 📋 Готовые программы с эспандером

- **6 новых программ тренировок с эспандером**:
  - **Эспандер для начинающих** (25 мин, легко) - базовая тренировка всего тела
  - **Верх тела с эспандером** (30 мин, средне) - грудь, спина, плечи, руки
  - **Низ тела с эспандером** (30 мин, средне) - ноги и ягодицы
  - **Спина-броня** (25 мин, средне) - специализация на спину
  - **Жим-Тяга с эспандером** (35 мин, сложно) - классическая push-pull схема
  - **Тотальная мощь** (40 мин, сложно) - продвинутая силовая тренировка всего тела

### 🐛 Исправления

- **Исправлен баг с отображением количества упражнений в кастомных сетах**
  - Проблема: backend возвращал меньше упражнений, чем было сохранено (дедупликация по exercise_id)
  - Причина: SQLAlchemy `selectinload()` дедуплицировал записи с одинаковым exercise_id
  - Решение: загрузка exercise данных отдельно в Map, затем ручное построение response
  - Файл: `custom_routines.py` - функция `get_custom_routine()`
  - Теперь корректно работают сеты с дубликатами упражнений

- **Исправлена ошибка удаления кастомных сетов**
  - Проблема: `SyntaxError: Failed to execute 'json' on 'Response'`
  - Причина: API клиент пытался распарсить JSON из 204 No Content response
  - Решение: проверка статуса 204 перед вызовом `response.json()`
  - Файл: `client.ts` - обработка 204 статуса перед JSON парсингом

- **Исправлена иконка warning в модальных окнах**
  - Проблема: отображалась только точка без треугольника
  - Решение: переделан SVG path - filled треугольник + негативное пространство для восклицательного знака
  - Файл: `PixelIcon.svelte`

- **Исправлено переполнение табов категорий за пределы экрана**
  - Проблема: табы категорий сетов выходили вправо за границу экрана
  - Решение: добавлен `flex-wrap: wrap` в компонент `PixelTabs`
  - Теперь табы переносятся на новую строку при нехватке места

- **Добавлено модальное окно подтверждения удаления кастомного сета**
  - Заменён двойной тап на полноценное модальное окно с предупреждением
  - Унифицированный UX с удалением друзей
  - Файл: `workout/+page.svelte` - состояние `confirmDelete` и модальное окно

- **Добавлена группировка избранных упражнений по категориям**
  - Избранные упражнения теперь отображаются с заголовками категорий

  - Сортировка по `sort_order` категорий
  - Файл: `workout/+page.svelte` - `groupedFavorites` derived variable

- **Исправлена возможность добавлять одно и то же упражнение несколько раз в кастомный сет**
  - Раньше: редактор блокировал добавление дубликатов упражнений, backend падал с 500 ошибкой при сохранении
  - Сейчас: можно добавлять одно и то же упражнение много раз для разных этапов тренировки
  - Frontend (`CustomRoutineEditor.svelte`):
    - Убрана проверка `selectedExercises.some(e => e.exercise.id === exercise.id)` из функции `addExercise`
    - Убраны визуальные индикаторы "уже добавлено" (disabled состояние, иконка check, прозрачность)
    - Изменён ключ в `#each` цикле с `item.exercise.id` на `index` для поддержки дубликатов
  - Backend (`custom_routines.py`):

## [1.0.0] - 2024-12-30

### 🎉 Первая рабочая версия

Первая стабильная версия BodyWeight Fitness - Telegram Mini App для отслеживания тренировок с геймификацией.

### ✨ Основные функции

#### 🏋️ Тренировки
- Создание и отслеживание активных тренировок
- Завершение тренировок с автоматическим расчётом XP и монет
- История тренировок с пагинацией
- Статистика за сегодня
- Отмена активных тренировок

#### 💪 Упражнения
- **242 упражнения** с прогрессиями и категориями
- 5 категорий: Strength, Cardio, Static, Dynamic Stretch, Static Stretch
- Фильтрация по категориям, сложности, тегам, оборудованию
- Система избранных упражнений
- Детальная информация об упражнениях
- Прогресс по каждому упражнению (всего повторений, лучший сет, количество выполнений)

#### 🎮 Геймификация
- **Система уровней и XP**
  - Автоматический расчёт XP за каждый подход
  - Формула: `base_xp × difficulty_mult × streak_mult × volume_mult × first_bonus`
  - Убывающая отдача после 20 повторений
  - Бонус за первый подход упражнения
  - Множитель за streak
- **Монеты**
  - Начисление за XP (пороговые значения)
  - Бонус за streak
  - Бонус за длительные тренировки
  - Бонус за достижения
  - Бонус за повышение уровня (5 монет за уровень)
- **Достижения (34)**
  - Автоматическая проверка при завершении тренировки
  - Уведомления о новых достижениях
  - Категории: первая тренировка, серии, объёмы, уровни
- **Streak-система**
  - Отслеживание ежедневных тренировок
  - Множитель XP за streak
  - Визуализация в профиле

#### 🏆 Социальные функции
- **Лидерборды**
  - Глобальный рейтинг по общему XP
  - Недельный рейтинг (XP за неделю)
  - Рейтинг друзей
  - Отображение позиции пользователя
- **Система друзей**
  - Отправка запросов в друзья
  - Принятие/отклонение запросов
  - Список друзей с фильтрацией
  - Просмотр профилей друзей

  - Платные: Phoenix, Griffin, Cerberus, Thunder Fang, Cyber Ape, Hydra, Minotaur, Kraken, Leviathan, Titan
